# Diabetes Prediction: Replication and Dataset Extensions

## Project Overview

This repository contains a partial replication and extension of machine learning methods for diabetes prediction, based on the study by Tasin et al. (2023).

The project investigates the reproducibility of diabetes prediction experiments and explores model behaviour using an additional public dataset and constructed synthetic records.

## Project Notebooks

1. **Copy of COMP8240_Tasin_Replication.ipynb** — Original-paper replication attempts and machine learning experiments.
2. **Copy of COMP8240_New_Dataset_Extension.ipynb** — Experiments using the UCI Early Stage Diabetes Risk Prediction dataset, including data cleaning and evaluation.
3. **Copy of COMP8240_Synthetic_Dataset_Extension.ipynb** — Construction of synthetic diabetes-related profiles and model prediction experiments.

## Datasets

The experiments use publicly available diabetes datasets and a separately constructed synthetic dataset.

Dataset sources, preprocessing decisions, redistribution permissions, and execution requirements will be documented before the repository is considered fully reproducible.

## Research Limitations

This is a partial replication rather than an exact reproduction of the original study.

Synthetic predictions are model outputs, not medically verified diagnoses. The models have not been clinically validated and should not be used for medical decision-making.

## Reproducibility

The notebooks were developed using Python and Google Colab. Dependencies, dataset-loading instructions, and clean-run verification are being prepared.

## Academic Context

Developed as part of COMP8240 — Applications of Data Science, Macquarie University.
